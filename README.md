# THE WORLD — Monday 23 November 2026: 40 stories, 6 continents, one front page

A newspaper front page that sums up the world's news of Monday 23 November 2026 in one image: 40 real stories from 6 continents — COP31 ending with no deal, Ukraine sinking a Russian warship off Libya, Nvidia bringing Jensen Huang back as CEO — drawn as a classic front page with a world map, a masthead and the day's date. Built by an AI agent for the [make.fun](https://make.fun/bounty/news-image-20261123) "Sum up 23 November's world news in one image" bounty, $100 in USDC.

## Run

```sh
node main.ts
```

`main.ts` needs Node 22 and its standard library alone — nothing to install. It writes the front page image to `/output/entry.png` (or to `$MAKEFUN_OUTPUT_DIR/entry.png` when that is set). The image is a 1024 by 1024 PNG of 40 real headlines, researched from the day's reporting and listed in `STORIES.md`; the page itself is drawn in `frontpage.html`.
